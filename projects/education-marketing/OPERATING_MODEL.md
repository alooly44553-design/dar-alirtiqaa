# نموذج التشغيل المستقل — التسويق والإعلام التعليمي

**النطاق:** منظومة مدارس ومراكز دار الإرتقاء الفكري التعليمية فقط.

**استثناءات إلزامية:** لا إدارة ولا محتوى ولا سجلات ولا طواقم ولا بيانات ولا تكاملات مشتركة مع المنصة الصحية أو البطاقات أو الخدمات الحكومية والعامة أو أي مشروع آخر. لا تستعمل قاعدة بيانات مشروع آخر أو مفاتيح API أو مجموعات مراسلة أو مجلدات أصول مشتركة. لا يُضاف خيار هذا المجال إلا إلى الصفحة الرئيسية التعليمية، وتبقى جميع صفحاته الفرعية ضمن نطاق التسويق التعليمي.

## بنية وحدة «أعمال الإرتقاء الفكري»
1. الصفحة الرئيسية التعليمية: مدخل واحد إلى أعمال الإرتقاء الفكري.
2. لوحة أعمال الإرتقاء الفكري: تعرض مجالات العمل التعليمية فقط.
3. كل مجال يفتح صفحة رئيسية مستقلة تحتوي على لوحة المهام، الجدول، السجل، الفريق، الأصول، حالة التنفيذ، ومؤشرات الأداء الخاصة بذلك المجال.
4. تخزين منفصل باسم نطاق واضح `education_marketing` مع صلاحيات حسب الدور، وسجل تدقيق، وتصدير واستعادة منفصلين. لا يُفعّل التخزين الحي قبل تطبيق مخطط البيانات ومراجعة الصلاحيات.

## المجالات التشغيلية
- الاستراتيجية والحملات التسويقية.
- مكتبة المحتوى والنصوص متعددة اللغات واللهجات.
- التصاميم والصور والملصقات والبرشورات.
- الفيديو والريلز والقصص والمواد الصوتية.
- النشر والجدولة وإعادة التهيئة لكل منصة.
- القنوات والصفحات والمجتمعات التعليمية.
- الرسائل والردود والأسئلة الشائعة.
- الاستفسارات والقبول والتسجيل والإحالة إلى نموذج التسجيل الرسمي.
- الفعاليات والمسابقات والأنشطة التعليمية.
- التحليلات والتقارير والتحسين.
- فريق العمل وتوزيع المهام والتقويم التحريري.

## قواعد المحتوى والنشر
- يدعم العربية الفصحى والعربية العامة واللهجات المطلوبة، مع لغات أخرى حسب الجمهور؛ تُراجع الترجمة والمعلومات التعليمية الحساسة قبل النشر.
- يمكن إعداد المسودات والمواد والجداول تلقائيًا. النشر الفعلي يتطلب اتصالًا رسميًا وصلاحيات للقناة. لا تتجاوز المنظومة قيود المنصات أو أنظمة مكافحة الرسائل المزعجة، ولا ترسل رسائل جماعية غير مطلوبة.
- لا تُنشأ حسابات أو مجموعات أو صفحات خارجية نيابةً عن الإدارة دون صلاحية موثقة على المنصة المعنية.
- لا يُنتحل صوت أو صورة أو توقيع المدير الإداري علي سليمان الأهدل أو مديرة المدرسة أمل محمد برديني، ولا يُخفى عن الجمهور أن الرد الآلي مساعد ذكي. يمكن اعتماد نبرة مؤسسية ودودة بعد موافقة أصحاب الأسماء على استخدام صورهم أو أصواتهم.
- لا يُعلن عن رسوم أو مقاعد أو اعتمادات أو نتائج قبول إلا وفق البيانات المعتمدة. استلام الطلب لا يعني القبول النهائي.
- تُحمى بيانات الأطفال وأولياء الأمور، ولا تُجمع إلا البيانات الضرورية عبر قنوات التسجيل المعتمدة.

## مسار العمل القياسي
1. تحديد المجال والجمهور والهدف والحملة.
2. إنشاء موجز ورسائل رئيسية ونسخ متنوعة.
3. توليد/تجهيز الأصول البصرية والفيديو والنصوص.
4. فحص الدقة واللغة وحقوق الاستخدام وخصوصية الأطفال.
5. تهيئة نسخة مناسبة لكل قناة.
6. إدراج الموعد في جدول النشر الخاص بالقناة.
7. النشر عبر التكامل الرسمي المتاح أو تسليم مسودة جاهزة للنشر.
8. استقبال التفاعل وتصنيفه والرد وفق قاعدة معرفة تعليمية معتمدة.
9. إحالة التسجيلات والطلبات إلى المسار التعليمي الرسمي دون قبول آلي نهائي.
10. قياس الوصول والتفاعل والاستفسارات والتحويلات وتوثيق النتائج.

## حالات المهمة
`idea` → `draft` → `asset_ready` → `fact_checked` → `scheduled` → `published` → `measured`؛ مع `blocked` و`failed` لتوثيق الأعطال. لا يُعرض أي عنصر على أنه منشور ما لم تؤكد المنصة المستهدفة نجاح النشر.

## متطلبات الإطلاق الفعلي
- صفحة مستقلة داخل المنصة التعليمية، لا تظهر إلا من المدخل التعليمي المحدد.
- جداول مستقلة للمهام والحملات والأصول والقنوات والمنشورات والرسائل والاستفسارات والفعاليات والطواقم وسجل التدقيق.
- فصل صلاحيات الكاتب والمصمم والمجدول والمشرف والمسؤول.
- اتصال رسمي منفصل لكل قناة، وتخزين الأسرار على الخادم فقط.
- اختبارات عزل تثبت عدم إمكان الوصول إلى بيانات أو وظائف المشاريع الأخرى.
- اختبارات نشر تجريبية، ومنع التكرار، ومحددات المعدل، وسجل أخطاء، وآلية إيقاف فوري.
- سياسة خصوصية وشروط استخدام معتمدة، وآلية موافقة مناسبة عند جمع بيانات التسجيل.
- تقارير أداء مرتبطة بالحملة والقناة والمجال التعليمي.

## الحالة التنفيذية
هذا الملف يحدد نطاق العمل وعقده التشغيلي، ولا يعني أن الواجهات أو الجداول أو اتصالات الشبكات الاجتماعية أو الردود الآلية قد بُنيت أو فُعّلت بالفعل. تُسجّل كل وظيفة على أنها «منفذة» فقط بعد وجود تنفيذ واختبار موثق.
