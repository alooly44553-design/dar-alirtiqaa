مدارس دار الارتقاء الفكري — النسخة الجاهزة للنشر

index.html  الموقع العام، يفتح مباشرة دون تسجيل دخول.
admin.html  لوحة الإدارة، وتطلب تسجيل الدخول للحساب الإداري.

تم إعداد الاتصال بالمشروع الموجود في Supabase داخل لوحة الإدارة باستخدام Publishable Key فقط.
لا تضع أي service_role أو secret key في ملفات الموقع.

النشر على Netlify:
1) ارفع مجلد المشروع كما هو أو ارفع الملفات داخل المجلد.
2) اجعل index.html هو الصفحة الرئيسية.
3) بعد النشر افتح الموقع العام، ثم اضغط «دخول الإدارة».
