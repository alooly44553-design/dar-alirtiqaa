# تقرير جاهزية ربط القنوات والردود الذكية — دار الإرتقاء الفكري

آخر تدقيق: 18 أكتوبر 2026  
الموقع: https://alirtiqaa-educational-platform.vercel.app/  
مركز الدخول الموحد لإعداد القنوات: https://alirtiqaa-educational-platform.vercel.app/connect-channels.html

## خلاصة القرار

لا يوجد رابط رسمي واحد يمنح ChatGPT كل صلاحيات النشر وقراءة الرسائل والرد على جميع القنوات. يختلف نوع الاتصال بين نشر القنوات، ومحادثات خدمة العملاء، وإدارة المجموعات، وجدولة المنشورات. يجب اختيار واجهة رسمية لكل نوع مع تفويض الحساب والصلاحيات اللازمة.

صفحة مركز القنوات هي نقطة بداية مركزية فقط؛ فتحها لا يفعّل أي اتصال تلقائيًا، ولا ينبغي عرض أي قناة بوصفها متصلة ما لم ينجح اختبار حقيقي.

## حالة المشروع وقت التدقيق

- لا تظهر متغيرات بيئة مخصصة لـ WhatsApp Business أو Telegram Bot أو OpenAI API في المتغيرات التي تم فحصها بمشروع Vercel.
- مراجعة ملفات المشروع لم تُظهر مسارات webhook قائمة لواتساب أو تليجرام؛ ملفات API الظاهرة تتركز على خدمات التعليم والتسجيل.
- Metricool متصل بملف علامة «مدارس دار الإرتقاء الفكري». عينة منشورات الجدول التي فُحصت تستهدف Facebook وLinkedIn.
- عيّنة الجدولة من 18 أكتوبر إلى 16 ديسمبر 2026: 47 عنصرًا، منها 20 مسودة و27 عنصرًا مجدولًا مع autoPublish=true. لم تكن الوسائط مرفقة إلا في عنصر واحد من العناصر الـ47، وظهرت 20 مجموعة من النصوص المتكررة مرتين. تُراجع قبل اعتماد الحملة النهائية.
- لم يجر تعديل مواعيد Metricool أو حذف المنشورات خلال هذا التدقيق.

## التفريق بين أنواع القنوات

### 1. قناة واتساب العامة (WhatsApp Channel)

قنوات واتساب مساحة تحديثات أحادية الاتجاه؛ متابعو القناة لا يرسلون ردًا مباشرًا على تحديثات القناة. وثائق WhatsApp Business Platform المنشورة تركز على محادثات العملاء عبر Cloud API، ولا يظهر بها مسار رسمي لإدارة منشورات WhatsApp Channels. لذلك:
- إدارة منشورات القناة وتحديثاتها: تتم من داخل تطبيق واتساب أو من خلال مشرف مُضاف رسميًا إلى القناة؛ لا نَعِد بنشر آلي من خلال Cloud API.
- استفسارات العملاء: تُعالج عبر محادثات واتساب للأعمال ورقم خدمة العملاء بعد تهيئة Cloud API منفصلًا.

مراجع:
- https://faq.whatsapp.com/809740894165112
- https://faq.whatsapp.com/360977646301595
- https://business.whatsapp.com/developers/developer-hub/
- https://www.postman.com/meta/whatsapp-business-platform/documentation/wlk6lh4/whatsapp-cloud-api

### 2. محادثات WhatsApp Business

المتطلبات قبل التنفيذ:
- حساب Meta Business وWhatsApp Business Account.
- رقم عمل مهيأ على WhatsApp Business Platform.
- Meta App والصلاحيات المناسبة، ومعرّفات الحساب والرقم.
- رمز وصول محفوظ في متغيرات البيئة السرية على Vercel، وليس في HTML أو GitHub أو المحادثات.
- endpoint webhook آمن، والتحقق من التوقيع/الـ verify token، ثم اختبار استقبال رسالة وإرسال رد.
- ضبط السياسات والقوالب ونافذة خدمة العملاء، وتحديد طريقة التصعيد إلى الموظف.

لا يُفترض أن API الرسمي قادر على قراءة أو نشر منشورات قناة واتساب؛ يجب اختبار محادثات خدمة العملاء فقط.

### 3. تليجرام

المتطلبات:
- إنشاء بوت من https://t.me/BotFather.
- حفظ token في Vercel Environment Variables، وعدم إرساله في الرسائل.
- إضافة البوت إلى القناة بصفة مدير مع صلاحية النشر إن كان الهدف نشر تحديثات القناة.
- إضافة البوت إلى المجموعة وضبط privacy mode وصلاحياته بحسب نوع الرسائل المطلوب استقبالها.
- تنفيذ webhook على HTTPS، والتحقق من secret token، ثم اختبار رسالة واردة ورد صادر.
- البوت لا يستطيع ضمان رؤية جميع رسائل مجموعة ما لم تكن إعداداته وصلاحياته مناسبة؛ اختبر مع مجموعة تجريبية قبل التفعيل.

المراجع:
- https://core.telegram.org/bots
- https://core.telegram.org/bots/api
- https://core.telegram.org/bots/webhooks

مسار webhook المقترح للمشروع بعد تنفيذ الكود والتهيئة (ليس مفعّلًا حاليًا):
https://alirtiqaa-educational-platform.vercel.app/api/connectors/telegram/webhook

### 4. Facebook وInstagram وLinkedIn وTikTok وYouTube

- تُستخدم Metricool للحملات والجدولة في الشبكات التي يثبت اتصالها وتوفر النشر فيها.
- أدوات Metricool المتاحة حاليًا في جلسة العمل تسمح بفحص الجدول وإنشاء المنشورات أو تعديلها وإرسالها للمراجعة، ولا تقدم ضمن مجموعة الأدوات الظاهرة واجهة موحدة لإدارة كل الرسائل الخاصة والتعليقات.
- تحتاج رسائل الصفحات والتعليقات إلى دعم رسمي مستقل لكل منصة أو مزود إدارة مجتمع يصرّح صراحةً بخدمة صندوق الرسائل المطلوب.
- لا يثبت وجود رابط صفحة عامة وحده أن صلاحيات API أو النشر قد فُعّلت.

### 5. الاتصال الأصلي داخل ChatGPT

التطبيقات المخصصة ذات صلاحيات الكتابة تعتمد على إعداد خادم MCP/تطبيق مخصص وتوثيقه، وتخضع لخطة ChatGPT وصلاحيات مساحة العمل. توضح وثائق OpenAI أن دعم MCP الكامل مع إجراءات الكتابة متاح لخطط Business وEnterprise/Edu، وأن دعم Pro للتطبيقات المخصصة مقيّد بالقراءة/الجلب في الوضع المطور. لا يوجد مسار موثوق لتجاوز هذه القيود من خلال رابط قناة عام.

مرجع OpenAI:
https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt

يمكن بدلًا من ذلك تشغيل أتمتة مستقلة على الخادم تستخدم OpenAI API، لكن هذا يتطلب API key منفصلًا وفوترة API مستقلة عن اشتراك ChatGPT؛ يجب إعداد متغيرات السرية واختبار الخدمة قبل تفعيل الرد الآلي.

## الحوكمة الآمنة للردود التلقائية

الرد الآلي المناسب:
- يجيب عن الأسئلة المتكررة باستخدام معلومات معتمدة ومحدّثة فقط.
- يشارك رابط صفحة الخدمة أو التسجيل ويشرح أن إرسال الطلب لا يساوي القبول النهائي.
- لا يخترع أسعارًا أو مقاعد أو مواعيد أو اعتمادات أو وعود قبول.
- لا يطلب كلمات مرور أو بيانات دفع أو معلومات طلاب حساسة عبر قناة عامة.
- يحوّل الحالات إلى الموظف عند الشكاوى، أو النزاع على رسوم، أو الدفع، أو طلبات حذف البيانات، أو شؤون الأطفال والبيانات الحساسة، أو الأسئلة القانونية/الطبية، أو أي جواب غير مؤكد.
- يسجل حالة التسليم والأخطاء، ويمنع الردود المكررة والرسائل الحلقية، مع حدود معدل وإعادة محاولات.
- يوضح للمستخدم عند اللزوم أن الرد صادر عن مساعد آلي.

## ضوابط التسويق والنشر

1. يبقى ترتيب المجالات كما اعتمدته الإدارة:
   الطفولة والتأسيس؛ التعليم الأساسي والعام؛ التعليم الجامعي والعالي؛ التدريب المهني والتقني؛ القرآن والإسلامية؛ التقوية والعربية والتأهيل؛ الإرشاد الأكاديمي؛ ثم باقي المجالات التعليمية والتربوية والترفيهية.
2. لا تُطلق منشورات بلا تصميم/وسائط لازمة، ولا تكرر المنشورات بالخطأ.
3. تُرسل المسودات والمطبوعات للمراجعة قبل النشر ما لم يصدر تفويض واضح مختلف.
4. لا يُنشر تلقائيًا محتوى يتضمن رسومًا أو تواريخ أو شهادات أو اعتمادات غير مؤكدة.
5. بعد تفعيل أي اتصال، اختبر الاستقبال والرد والنشر في نطاق خاص أولًا؛ احتفظ بسجل للاختبار قبل وصف الربط بأنه ناجح.
