شروط الاستخدام

منظومة مدارس / مراكز دار الإرتقاء الفكري التعليمية
مسودة للمراجعة والاعتماد الإداري والقانوني قبل اعتبارها شروطًا نهائية. لا تُستخدم هذه الصفحة بديلًا عن مراجعة قانونية محلية أو عن سياسة الرسوم والاسترداد المعتمدة.

1. قبول الشروط

باستخدام الموقع أو إرسال نموذج، يقر المستخدم بأنه قرأ الإرشادات الموضحة في الصفحة. استخدام بعض البوابات يتطلب حسابًا وصلاحية معتمدة، وتظل الخدمات خاضعة للمتطلبات والإجراءات المعتمدة لدى الإدارة.

2. طلبات التسجيل والخدمات

إرسال طلب تسجيل أو استفسار أو طلب خدمة يعني استلامه للمراجعة فقط. ولا يمثل بذاته قبولًا نهائيًا، أو ضمان مقعد، أو تأكيد موعد، أو اعتماد مؤهل، أو التزامًا بتقديم برنامج أو خدمة أو فرض رسوم محددة. تؤكد الإدارة التوفر والمتطلبات والتكلفة والشروط كتابةً عبر قناة معتمدة قبل أي التزام نهائي.

3. صحة البيانات

يلتزم المستخدم بتقديم بيانات دقيقة ومحدثة وعدم استخدام بيانات شخص آخر دون صلاحية. وقد تطلب الإدارة استكمال بيانات أو مستندات لازمة للتحقق من الطلب. لا ترسل المستندات الحساسة عبر قنوات عامة؛ وتظل ميزة رفع المرفقات العامة غير مفعّلة في الوقت الحالي.

4. الحسابات والصلاحيات

  • يُستخدم كل حساب من صاحبه، وتُحفظ بيانات الدخول بسرية.
  • لا يجوز مشاركة الحسابات أو محاولة تجاوز حدود الدور والصلاحيات.
  • يُبلغ المسؤول المختص عند الاشتباه في استخدام غير مصرح به.
  • الوصول إلى بيانات الطالب أو ولي الأمر أو المعلم يتم وفق الربط والصلاحيات المعتمدة فقط.

5. الاستخدام المقبول

لا يجوز استخدام المنصة لتعطيل الخدمة، أو محاولة الوصول غير المصرح به، أو إدخال محتوى ضار أو مضلل، أو انتهاك خصوصية الآخرين، أو نسخ المحتوى واستخدامه بما يخالف الحقوق أو القواعد المنطبقة.

6. المحتوى التعليمي والاعتماد

المعلومات التعليمية والتعريفية المنشورة تهدف إلى الإرشاد وتوضيح المجالات والخدمات. لا ينبغي تفسير ذكر مجال دراسي أو تدريب أو شهادة على أنه اعتماد رسمي من جهة خارجية، أو اعتراف أكاديمي، أو ضمان نتيجة. تخضع البرامج والمؤهلات وأي اعتماد لشروط الجهات المختصة وما يتم تأكيده رسميًا.

7. توفر المنصة والتغييرات

قد تختلف بعض الوظائف بحسب الحساب أو البرنامج أو الإعدادات أو توافر مزودي الخدمة والاتصال بالإنترنت. يمكن أن تُحدّث الواجهات أو توقف وظيفة للصيانة أو الأمان. لا تُعلن الوظيفة متاحة ما لم تكن مفعلة ومختبرة؛ ويُرجع إلى الإدارة للتأكيد في الحالات التي تتطلب قرارًا أو موافقة بشرية.

8. البيانات والخصوصية

تقرأ هذه الشروط مع سياسة الخصوصية. يجب على الإدارة اعتماد نصوص السياسة وشروط استخدام البيانات والرسوم والاسترداد وآلية الشكاوى قبل الإطلاق العام النهائي.

9. المراجعة والتواصل

يمكن إرسال الاستفسارات الأولية عبر قناة دار الإرتقاء الفكري على تيليجرام. ينبغي اعتماد بيانات التواصل الرسمية وإضافة إجراء واضح للشكاوى والبلاغات قبل النشر النهائي.
