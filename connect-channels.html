مركز إعداد قنوات دار الارتقاء الفكري

نقطة دخول واحدة إلى الروابط الرسمية لإعداد النشر وخدمة الاستفسارات.

تنبيه: هذه الصفحة تجمع روابط الإعداد فقط. لا تمنح صلاحيات تلقائية ولا تعني أن أي قناة متصلة. لا تشارك كلمات المرور أو رموز البوتات أو مفاتيح API في هذه الصفحة أو المحادثة.

1. إدارة المنشورات والتصاميم

فتح تقويم Metricool الخاص بالمدارس

عرض تصميم حزمة المسارات التعليمية في Canva

راجع المنشورات المتكررة وأرفق الوسائط المناسبة قبل اعتماد أي حملة. تبقى التعديلات والنشر للمراجعة قبل الإطلاق.

2. إعداد واتساب للأعمال

فتح بوابة WhatsApp Business Platform الرسمية

يحتاج الرد الآلي على محادثات العملاء إلى حساب أعمال ورقم مهيأ وصلاحيات API وWebhook آمن. قناة WhatsApp العامة ليست هي صندوق رسائل العملاء، ولا يوجد في المشروع اتصال آلي مؤكد بها.

3. إعداد بوت تليجرام

فتح BotFather لإنشاء بوت

دليل Webhooks الرسمي لتليجرام

بعد إنشاء البوت، أضفه للقناة أو المجموعة بالصلاحيات اللازمة، واحفظ الرمز في إعدادات سرية على الخادم. لا تضع الرمز في ملفات عامة.

4. ربط تطبيق مخصص بـ ChatGPT

دليل OpenAI الرسمي لربط خوادم MCP مخصصة

الربط يتطلب خادمًا موثقًا وصلاحيات متوافقة مع خطة ChatGPT. البديل هو أتمتة مستقلة تستخدم OpenAI API، مع مفتاح API منفصل محفوظ بأمان.

5. متطلبات التشغيل الآمن

  1. تفويض كل قناة من مالك الحساب عبر واجهتها الرسمية.
  2. إعداد مفاتيح الوصول كمتغيرات سرية على الخادم.
  3. اختبار استقبال رسالة وإرسال رد ونشر تحديث تجريبي قبل التفعيل.
  4. قصر الردود الآلية على معلومات معتمدة؛ تحويل الشكاوى والمدفوعات وشؤون الأطفال والبيانات الحساسة والأسئلة غير المؤكدة إلى الموظف.
  5. عدم اعتبار أي اتصال ناجحًا حتى يثبت باختبار موثق.

دار الارتقاء الفكري — صفحة إرشادية للإعداد الرسمي. حالة واتساب وتليجرام في المشروع: غير مفعّلتين حتى الآن.
