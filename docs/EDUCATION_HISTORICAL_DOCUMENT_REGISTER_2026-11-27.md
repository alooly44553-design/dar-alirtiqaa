## 4. تصحيح القراءة التشغيلية

1. لا يُساوى بين إصدار QA 1.1.10 وإصدار الإنتاج؛ لكل بيئة إعداداتها ونشرها.
2. حالة Vercel `READY` تثبت نجاح عملية البناء/النشر فقط، ولا تثبت وحدها اختبار جميع المسارات أو الأدوار.
3. إفادة الدخول إلى البوابات لا تثبت تلقائيًا سلامة عزل بيانات الطلاب أو حدود صلاحيات API.
4. تقرير QA الخاص بمزودي المعالجة لا يثبت مواقع معالجة الإنتاج أو شروط العقود.
5. لا يُحذف أي تقرير تاريخي أو أصل أو فرع أو نسخة احتياطية ضمن C-02.
6. أي تحديث لصورة الهوية أو الشعار أو أيقونات التطبيق والصفحات مؤجل إلى حين تثبيت ملف الصورة الأصلية الجديدة ومقارنته بالأصل المعتمد، ثم حصر كل مواضع الاستخدام قبل التعديل. لا يُستبدل ختم أو شعار بعنصر إعلاني.

## 5. العناصر التي تتطلب قرارًا أو دليلًا إضافيًا

- تحديد ملف الصورة الأصلية الجديدة المقصودة تحديدًا (الشعار، صورة الهوية الكاملة، أو كليهما) قبل تعديل الأصول والواجهات.
- استكمال نتائج الاختبارات التفصيلية لكل دور، مع بيان ما أمكن عرضه أو تعديله وما رُفض.
- مراجعة قائمة المسارات والأصول المستخدمة فعليًا قبل أي استبدال شامل.
- عدم تعديل ملفات الإنتاج أو نشر فرع التنظيف قبل اعتماد مستقل.
