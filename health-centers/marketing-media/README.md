# مكتب الإعلام والتسويق الصحي — مراكز الإرتقاء الفكري الصحية

## الغرض
مساحة مستقلة لصناعة المحتوى الصحي التوعوي والإعلاني وتنظيم حملاته وتغطية الأنشطة والفعاليات والمشاركات والرحلات المرتبطة بالمنظومة الصحية، دون إدارة الأعمال الطبية أو الإدارية أو الإشرافية أو المهنية.

## الملفات
- `index.html`: واجهة أولية تفاعلية لاستوديو المحتوى وتقويم الحملات والقنوات وصندوق التفاعل وسجل الأنشطة الإعلامية.
- تحفظ المسودات محليًا في المتصفح تحت مفتاح `irtiqaa-health-marketing-v1` فقط؛ لا توجد مزامنة بين الأجهزة أو قاعدة بيانات متصلة.

## حدود التشغيل الحالية
- لا تنشر الصفحة تلقائيًا على شبكات التواصل ولا ترسل رسائل أو تنشئ قنوات أو مجموعات فعلية.
- لا توجد حتى الآن مصادقة خادمية أو تكاملات OAuth/API أو تحليلات حية.
- مؤشرات التفاعل التي لم تُستورد من مصدر رسمي لا تُعرض كأنها أرقام فعلية.
- لا تحفظ بيانات مرضى أو تشخيصات أو معلومات صحية شخصية، ولا تستخدمها في التسويق.
- لا ترفع صور أشخاص أو تنشر معلومات عنهم دون تصريح مناسب؛ والمعلومات الطبية يجب أن يراجعها مختص مخوّل قبل النشر.

## العزل
- جميع الإضافات في هذا الفرع ضمن `health-centers/marketing-media/`.
- لا تغييرات على `main` ولا دمج تلقائي ولا تعديل على صفحات الإدارة أو الطاقم أو قاعدة البيانات أو تكاملاتها.
- لا يتيح هذا الفرع وصولًا إلى أنظمة التعليم أو المشاريع الأخرى أو بياناتها.
- أي نشر خارجي لاحق يتطلب ربطًا رسميًا، وتفويضًا من صاحب الحساب، واختبارات، ومراجعة صلاحيات مستقلة.

## الخطوات التالية قبل التشغيل الفعلي
1. مراجعة الواجهة والمحتوى مع ممثل مخوّل عن المنظومة الصحية.
2. بناء تخزين خادمي آمن وصلاحيات منفصلة عند الحاجة إلى مزامنة فريق التسويق.
3. ربط كل منصة عبر API/OAuth رسمي وفق ما تسمح به المنصة.
4. اختبار الجدولة، ومنع التكرار، وسجل التدقيق، وفشل الاتصالات، وحماية الرموز.
5. اختبار النشر والرسائل على بيئة تجريبية ثم اعتماد التشغيل الفعلي.
