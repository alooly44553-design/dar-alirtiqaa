# مراكز الإرتقاء الفكري الصحية

تطبيق ويب عربي مستقل (RTL/PWA) بصفحات تنظيم الخدمات والمواعيد والطلبات الإدارية والخطط والبرامج والمهام والمناوبات والمخزون والتقارير ومحتوى المركز.

## حدّ التشغيل الحالي
- الواجهة والوظائف الأساسية تعمل في المتصفح.
- البيانات تحفظ محليًا في localStorage على الجهاز الحالي ولا تتزامن مع موظفين أو فروع أخرى.
- لا توجد قاعدة بيانات مركزية أو مصادقة أو صلاحيات خادمية في هذا الإصدار.
- لا تدخل بيانات مرضى أو تشخيصات أو معلومات طبية حساسة. هذا ليس سجلًا طبيًا آمنًا، والمواعيد ليست حجوزات مؤكدة.
- قبل التشغيل الحقيقي يجب بناء طبقة خلفية محمية مع مصادقة، وصلاحيات دقيقة، وسجل تدقيق، ونسخ احتياطي واستعادة، ومراجعة قانونية وأمنية.

## ملفات التطبيق
- index.html: غلاف التطبيق والتنقل.
- app.js: الصفحات والنماذج والحفظ المحلي والتصدير.
- styles.css: تصميم متجاوب للأجهزة.
- app.webmanifest وsw.js: تهيئة PWA والملفات الثابتة.
- privacy.html: توضيح حدود الخصوصية والاستخدام.
