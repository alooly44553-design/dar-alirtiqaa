# مراكز الإرتقاء الفكري الصحية — دليل التثبيت وحدود الإصدار

## روابط مباشرة
- التطبيق الرئيسي: https://al-irtiqaa-health-smart-global.vercel.app/
- بوابة دخول الإدارة: https://al-irtiqaa-health-smart-global.vercel.app/admin.html
- لوحة التشغيل والإدارة: https://al-irtiqaa-health-smart-global.vercel.app/admin-console.html

## التثبيت كـ PWA
- **Android (Chrome):** افتح رابط التطبيق ثم قائمة المتصفح واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية» إذا ظهر الخيار.
- **iPhone / iPad (Safari):** افتح رابط التطبيق، اضغط «مشاركة»، ثم «إضافة إلى الشاشة الرئيسية».
- **Windows / macOS (Chrome أو Edge):** افتح رابط التطبيق، ثم اختر «تثبيت التطبيق» من شريط العنوان أو قائمة المتصفح إن ظهر الخيار.

هذا الإصدار تطبيق ويب تقدّمي (PWA) يعمل عبر الرابط. لا يتضمن المستودع بناء APK أندرويد أصليًا أو IPA آيفون أصليًا أو حزم تثبيت سطح مكتب مستقلة؛ لذلك لا يُقدَّم رابط تحميل لملفات لم تُبنَ.

## حدود التشغيل التي يجب مراعاتها
- لوحة الإدارة تستخدم API محميًا بالجلسة والصلاحيات؛ يجب الدخول بحساب مصرح به.
- إضافة الموظف لا تمنحه صلاحية تلقائيًا: يلزم بريد موثق، وربط الهوية، ثم التفعيل الصريح.
- استقبال طلبات المواعيد العامة يبقى معطلًا حتى تفعيل سياسة الاستقبال واختبار مسار الطلب والخصوصية.
- أدوات التخطيط في التطبيق الرئيسي ولوحة التجهيز تحفظ بياناتها محليًا في متصفح الجهاز، ولا تتزامن مع بقية المستخدمين.
- لا تعتبر الإعلانات أو صفحات دليل الخدمات دليلًا على وجود طاقم مرخّص أو منشأة مجهزة أو موعد طبي فعلي.

## ما يلزم قبل إطلاق الخدمات للجمهور
اختبار المتصفح من جهاز مستخدم فعلي، واختبار إنشاء/تعديل/إيقاف مركز وموظف وطلب على بيئة معتمدة، ومراجعة الخصوصية والاحتفاظ بالبيانات، ثم اعتماد تفعيل استقبال الطلبات. لا تُستخدم بيانات مرضى حقيقية في الاختبار.
