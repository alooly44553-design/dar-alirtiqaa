# قائمة بوابة القبول النهائي — منظومة الإرتقاء الفكري الصحية

- التاريخ: 2026-10-25
- الحالة: **قائمة تحقق — ليست محضر قبول ولا إعلان جاهزية**
- مسؤول القبول النهائي المسجل: علي الأهدل — المدير الإداري، الإرتقاء الفكري الصحية.

## قاعدة التقييم
لكل بند حالة واحدة فقط: **ناجح / فاشل / غير مختبر / يحتاج اعتمادًا بشريًا**. لا يجوز وضع «ناجح» دون دليل قابل للفتح يشير إلى commit أو نسخة الاختبار نفسها. لا يساوي نجاح CI قبولًا أمنيًا أو قانونيًا أو سريريًا.

## بوابات حرجة قبل التشغيل العام

| الرمز | المتطلب | الحالة الابتدائية في هذا السجل | الدليل المطلوب |
|---|---|---|---|
| SCOPE-01 | نطاق إداري غير سريري ومنع البيانات الصحية الحقيقية | قيد التطبيق | قرار النطاق وتعليمات الواجهة |
| AUTH-01 | رفض الطلب بلا جلسة أو برمز غير صالح | توجد اختبارات معزولة لبعض الحالات؛ يلزم تكامل | سجل اختبارات على commit المرشح |

| ISO-01 | عزل القراءة والكتابة بين مركزين | غير مثبت | اختبار تكامل بقاعدة اختبار |
| DB-01 | ترحيلات غير هدامة مراجعة ومختبرة | غير مثبت للإنتاج | مراجعة ترحيل ونتائج قاعدة اختبار |
| BACKUP-01 | استعادة نسخة احتياطية فعلية | غير مثبت | سجل استعادة مستقل وقياسات RPO/RTO |
| PRIV-01 | اعتماد إشعار الخصوصية وشروط الاستخدام | يحتاج اعتمادًا بشريًا | نسخة نهائية ومحضر اعتماد |
| INTAKE-01 | إبقاء استقبال الطلبات معطلًا قبل الاعتماد | يجب التحقق من الإعداد الفعلي | دليل إعداد بيئة النشر |
| EXT-01 | اختبار التكاملات دون إرسال/اجتماع فعلي غير مصرح | قيد الاختبار | سجلات اختبار ووجهات تجريبية |
| AND-01 | إصدار Android رسمي موقّع | غير مثبت؛ Debug لا يكفي | سجل Release وبصمة وتحقق التوقيع |
| CI-01 | فحوص النسخة المرشحة نفسها | لكل commit على حدة | روابط CI ومعرّف commit |
| OPS-01 | خطة المراقبة والحوادث والرجوع | يحتاج مراجعة | إجراءات تشغيل معتمدة |

## شروط منع القبول
- أي فشل أمني حرج أو اختبار عزل غير منفذ.
- عدم وجود دليل لاستعادة نسخة احتياطية عندما تكون مطلوبة للتغيير.
- عدم اعتماد الخصوصية وشروط الاستخدام.
- وجود اختلاف غير محلول في الصلاحيات أو سلوك الحسابات.
- استقبال بيانات حقيقية مفعّل دون اعتماد.
- وصف Debug APK بأنه رسمي أو موقّع دون دليل.
- وجود استثناء غير محدد المالك أو المدة أو المخاطر أو خطة الإغلاق.
