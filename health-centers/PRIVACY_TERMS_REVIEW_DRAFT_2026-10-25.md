# حزمة مراجعة الخصوصية وشروط الاستخدام — مسودة غير معتمدة

- التاريخ: 2026-10-25
- الحالة: **مسودة للمراجعة البشرية والقانونية — ليست سياسة نافذة أو اعتمادًا قانونيًا**
- المسؤول الإداري للتنسيق حسب سجل المشروع: المدير الإداري الذكي للمنظومة الصحية.
- مسؤول القبول النهائي المسجل: علي الأهدل — المدير الإداري، الإرتقاء الفكري الصحية.
- يلزم أن تعتمد الجهة المسؤولة/المراجع القانوني النسخة النهائية كتابةً قبل فتح استقبال الطلبات.

## 1. النطاق المعلن
المنصة مخصصة في المرحلة الحالية لأعمال إدارية وتنظيمية غير سريرية. لا يجوز إدخال تشخيصات أو وصفات أو نتائج فحوص أو ملفات مرضى أو بيانات صحية حساسة. يجب ألا تُفهم المنصة على أنها خدمة تشخيص أو علاج أو فرز طبي.

## 2. فئات البيانات التي قد تظهر في سير العمل
بحسب الوظائف المفعلة قد تشمل البيانات: اسم مقدم الطلب، وسيلة الاتصال، نوع الخدمة أو التخصص، التاريخ والوقت المفضلان، حالة الطلب، وسجلات إدارية ضرورية. هذه معلومات شخصية حتى إن لم تتضمن تشخيصًا طبيًا. يجب مراجعة كل حقل وتبرير ضرورة جمعه قبل التشغيل.

## 3. أغراض المعالجة — تحتاج اعتمادًا
- استقبال الطلب الإداري وتوجيهه إلى الجهة المختصة.
- إدارة المواعيد والردود والإشعارات المرتبطة بالطلب عند تفعيلها.
- حماية الخدمة ومراجعة الاستخدام غير المصرح به.
- حفظ سجل تدقيق محدود للعمليات الإدارية الضرورية.

لا تُفعّل أي غاية جديدة أو مشاركة خارجية قبل توثيقها واعتمادها.

## 4. عناصر يجب استكمالها قبل اعتماد النص النهائي
- [ ] الاسم القانوني للجهة المسؤولة ووسيلة الاتصال الرسمية.
- [ ] الأساس القانوني للمعالجة وفق الولاية القضائية المنطبقة.
- [ ] تحديد حقول البيانات الإلزامية والاختيارية ومبرر كل حقل.
- [ ] مدة الاحتفاظ لكل فئة، وآلية الحذف/التصحيح/الاعتراض حيث تنطبق.
- [ ] من يمكنه الوصول إلى البيانات، ومراجعة صلاحيات المراكز والموظفين.
- [ ] مزودو الاستضافة وقاعدة البيانات والمراسلة ومواقع المعالجة ونقل البيانات عبر الحدود.
- [ ] آلية الموافقة المناسبة حيث تكون مطلوبة، وإثباتها وسحبها.
- [ ] إجراءات الاستجابة للحوادث والإبلاغ والتواصل مع المتأثرين.
- [ ] سياسة ملفات تعريف الارتباط/التخزين المحلي والتحليلات إن وجدت.
- [ ] شروط الاستخدام المقبول وحدود مسؤولية الخدمة ومسار الشكاوى.
- [ ] مراجعة إمكانية الوصول واللغة العربية ووضوح النص للمستخدم.
- [ ] اسم المراجع القانوني/مسؤول الخصوصية، واسم صاحب الاعتماد وتاريخ الموافقة ورقم النسخة.

## 5. ضوابط تقنية وإدارية مقترحة
- تقليل البيانات إلى الحد الضروري، وعدم إدخال بيانات صحية حقيقية في بيئة الاختبار.
- فرض المصادقة والتفويض على الخادم وعزل بيانات كل مركز.
- منع ظهور البيانات الشخصية في سجلات الأخطاء والتحليلات غير الضرورية.
- تحديد مدد الاحتفاظ والحذف ونسخ الاحتياطي بوضوح.
- قصر الوصول الإداري على الحسابات المخولة، ومراجعة الحسابات المعطلة دوريًا.
- إبقاء استقبال الطلبات عبر الإنترنت معطلًا حتى اعتماد الوثائق واختبار سير العمل.

## 6. قرار الاعتماد
لا يُملأ هذا القسم إلا بعد المراجعة الفعلية:
- الجهة المسؤولة:
- المراجع القانوني/مسؤول الخصوصية:
- صاحب الاعتماد المخول:
- رقم النسخة النهائية:
- تاريخ الاعتماد:
- الشروط أو الاستثناءات:
- رابط محضر الاعتماد:

**لا تضع أسماء أو تواريخ افتراضية في خانات الاعتماد.** لا يثبت إنشاء هذه المسودة أن سياسة الخصوصية أو شروط الاستخدام قد اعتمدت قانونيًا.
