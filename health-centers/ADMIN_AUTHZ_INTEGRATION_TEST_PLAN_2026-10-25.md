# خطة اختبار التكامل للمصادقة والتفويض وعزل المراكز

- التاريخ: 2026-10-25
- الحالة: **خطة اختبار فقط — لم تُنفّذ اختبارات التكامل الواردة هنا بعد**
- البيئة المستهدفة: قاعدة اختبار مستقلة، وحسابات اصطناعية، وبيانات غير حقيقية.
- ممنوع: استخدام بيانات مرضى حقيقية، أو تشغيل اختبارات كتابة على الإنتاج، أو تخزين رموز JWT/أسرار في السجلات.

## الهدف
تقديم أدلة مستقلة عن اختبارات الوحدة تثبت أن API يطبق المصادقة والتفويض وعزل المراكز على الخادم، وليس اعتمادًا على إخفاء عناصر الواجهة.

## شروط البدء
- [ ] بيئة اختبار منفصلة عن الإنتاج ومثبتة في سجل التشغيل.
- [ ] حسابات اختبار: مدير منصة، مدقق منصة، مدير مركز A، موظف مركز A، مشاهد مركز A، مدير مركز B، حساب معطل، وحساب بلا دور.
- [ ] بيانات اختبار اصطناعية بعلامات مميزة لكل مركز.
- [ ] مراجعة نسخة المخطط والترحيلات في قاعدة الاختبار.
- [ ] تحديد طريقة إنشاء JWT اختبارية موثوقة دون نسخ أسرار الإنتاج.
- [ ] تأكيد أن الاختبارات لا يمكن أن تتصل بعنوان قاعدة الإنتاج.

## مصفوفة الاختبار المطلوبة

| الرمز | الحالة | النتيجة المتوقعة | حالة التنفيذ |
|---|---|---|---|
| AUTH-01 | طلب بلا Bearer token | 401 ولا استعلام بيانات | غير منفذ |
| AUTH-02 | JWT تالف أو منتهي | رفض المصادقة ولا تسريب تفاصيل | غير منفذ |
| AUTH-03 | هوية صحيحة لكن الحساب غير موجود/معطل | رفض الوصول | غير منفذ |
| AUTH-04 | دور غير معروف | رفض افتراضي، لا صلاحيات ضمنية | غير منفذ |
| AUTHZ-01 | موظف مركز A يقرأ قائمة الطاقم | بيانات A فقط | غير منفذ |
| AUTHZ-02 | موظف A يطلب أو يعدل موردًا تابعًا لـ B | رفض دون تعديل | غير منفذ |
| AUTHZ-03 | مشاهد المركز يحاول إنشاء/تعديل سجل | 403 أو رفض موثق | غير منفذ |
| AUTHZ-04 | مدير المركز يحاول قراءة سجل تدقيق المنصة أو الطلبات المركزية | رفض | غير منفذ |
| AUTHZ-05 | مدير المنصة بدور محدود يحاول تغيير إعدادات لا يملكها | رفض | غير منفذ |
| DATA-01 | تبديل معرف المركز في جسم الطلب | لا تجاوز للنطاق المصرح | غير منفذ |
| DATA-02 | حساب معطل بعد إنشاء الجلسة | يرفض وفق سياسة الجلسات المعتمدة | غير منفذ |
| LOG-01 | جميع حالات الرفض | لا رموز أو بيانات شخصية في السجل | غير منفذ |

## معايير النجاح
1. لا يُرجع أي استعلام بيانات مركز B إلى حساب مركز A.
2. التحقق من الصلاحيات يحدث في الخادم لكل إجراء قراءة أو كتابة.
3. اختبارات الرفض تؤكد عدم حدوث أي تغيير في قاعدة الاختبار.
4. تُحفظ سجلات CI ومعرّف commit وإصدار قاعدة الاختبار وملخص النتائج دون أسرار.
5. أي فشل أو حالة غير مختبرة تمنع إعلان اجتياز بوابة التكامل.
