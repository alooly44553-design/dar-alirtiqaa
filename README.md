# مدارس دار الارتقاء الفكري

منظومة تعليمية ذكية متكاملة للمدارس والمراكز والتعليم الإلكتروني والتعليم العالي والتدريب المهني.

## مكونات المنظومة
- الموقع العام: `index.html`
- لوحة الإدارة والتحكم الذكي: `admin.html`
- قاعدة البيانات والخدمات: Supabase
- تطبيق Android: Capacitor
- بناء APK: GitHub Actions عبر `.github/workflows/android-apk.yml`

## الحوكمة
القرار الإداري النهائي بيد الإدارة المخولة، والذكاء الاصطناعي يعمل كمشرف ومعلم ومساعد ضمن الصلاحيات والموافقات المحددة.

## البناء
يتم تشغيل بناء Android تلقائيًا عند الدفع إلى الفرع `main`، ويمكن تشغيل Workflow يدويًا من GitHub Actions.
