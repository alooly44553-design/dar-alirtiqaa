# مدارس ومراكز دار الارتقاء الفكري التعليمية

منظومة تعليمية رقمية موحدة لإدارة وتشغيل ومتابعة البرامج والخدمات التعليمية والتربوية والإدارية والتدريبية؛ من التعليم الأساسي والعام واللغات والمهارات الرقمية إلى التعليم العالي والإرشاد والتأهيل والتدريب المهني، إضافة إلى التسجيل والمتابعة والأنشطة والفعاليات والتواصل والتسويق وفق الصلاحيات المعتمدة.

## مكونات المنظومة
- الموقع العام والتعريف بالبرامج والخدمات: `index.html`
- لوحة الإدارة والتشغيل والحوكمة: `admin.html`
- بوابات المتعلمين وأعضاء التعليم: `portal.html` وصفحات البوابات المتخصصة
- قاعدة البيانات والخدمات: Supabase
- تطبيق Android: Capacitor
- بناء APK: GitHub Actions عبر `.github/workflows/android-apk.yml`

## التوجيه المباشر والمتابعة
- تسجيل التوجيهات داخل لوحة الإدارة دون نقل المستخدم إلى رابط أو صفحة أخرى.
- خيارات الإجراء: الاطلاع، المراجعة، المناقشة، التحديث، القبول، والرفض.
- تظهر أزرار الإجراء للحساب المقصود فقط، وتُسجّل القرارات والملاحظات في سجل تدقيق.
- القبول والرفض يسجلان قرارًا نهائيًا على التوجيه نفسه ولا يعدّلان تلقائيًا سجلات الطلاب أو الطواقم أو أي بيانات أخرى.
- لا يُنشأ للطواقم التشغيلية أي حساب مستقل تلقائيًا؛ الربط بالحسابات يتطلب إجراءً آمنًا موثقًا.

## الحوكمة والأمن
القرار الإداري النهائي بيد الإدارة المخولة، والذكاء الاصطناعي يعمل كمشرف ومعلم ومساعد ضمن الصلاحيات والموافقات المحددة. تُطبّق سياسات الوصول على مستوى قاعدة البيانات، ولا يُعد نجاح البناء وحده إثباتًا لاكتمال كل تكامل خارجي أو تشغيله فعليًا.

## البناء
يتم تشغيل بناء Android تلقائيًا عند الدفع إلى الفرع `main`، ويمكن تشغيل Workflow يدويًا من GitHub Actions.
